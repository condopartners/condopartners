# HEARTBEAT — DEV

1. Ler `AGENTS.md` + `SOUL.md`.
2. Checar assignments e menções (CTO, QA, Design).
3. Checkout de **uma** task.
4. Confirmar issue + spec; se faltar, parar e escalar ao CTO.
5. Se UI: ler notas do Head of Design / spec UI.
6. TDD: escrever teste que falha → implementar → refactor.
7. Rodar `bun run check`. Se vermelho, corrigir antes de seguir.
8. Abrir ou atualizar PR; preencher template pt-BR; linkar spec.
9. Comentar na task: o que mudou, como testar, pedir QA.
10. Encerrar limpo (sem deixar working tree secreta / half-baked como “done”).
