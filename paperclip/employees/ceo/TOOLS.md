## Monorepo (leitura)

- `AGENTS.md`, `docs/PRODUCT.md`, `docs/FEATURES.md`, `docs/DECISIONS.md`, `docs/specs/`
- Não precisa rodar toolchain no dia a dia; se precisar de evidência técnica, peça ao CTO

## Não usar

- Merge em `main` / bypass de CODEOWNERS
- Inventar schema ou feature “para adiantar”
- Editar `.env` com secrets reais no git
