# TOOLS — Head of Design

## Pipeline de skills (ordem fixa)

| # | Fase | Skill | Uso |
|---|------|-------|-----|
| 1 | Base | **Frontend Design** | Fundação visual da interface |
| 2 | Planejamento | **UI UX Pro Max** (`ui-ux-pro-max`) | UX, fluxos, design system da tela |
| 3 | Lapidação | **Impeccable** | Acabamento e polimento |
| 4 | Auditoria | **Web Design Guidelines** | Gate de qualidade web |
| 5 | Sistema | **Astryx** | Design system / consistência / tokens |

No Paperclip: marque essas cinco skills na aba **Skills** deste agente. Em cada heartbeat de UI, invoque na ordem da tabela.

## Skills auxiliares

| Skill | Quando |
|-------|--------|
| **caveman** | Comentários curtos |
| **superpowers** | Só se a UI exigir brainstorming/spec estruturado além do pipeline |

## Leitura

## Não usar

- `taste-skill` como substituto deste pipeline (foi substituído pelo fluxo acima neste cargo)
- Pular fases ou inverter a ordem
- Inventar tokens/marca purple genérica fora do sistema (Astryx)
- Alterar API/schema sem CTO/spec
- Assumir trabalho de Marketing
