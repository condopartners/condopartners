# HEARTBEAT — QA

1. Ler `AGENTS.md` + `SOUL.md`.
2. Checar assignments e pedidos de review (DEV/CTO).
3. Checkout de **uma** task de verificação.
4. Ler issue + spec + PR; listar critérios de aceite.
5. Rodar evidência: testes relevantes e/ou `bun run check`; smoke se UI.
6. Se falhar: comentar falhas com repro; devolver ao DEV; status bloqueado.
7. Se passar: comentar evidência (comandos, resultados); avisar CTO.
8. Não mergear — só sinalizar prontidão.
9. Extrair riscos/casos de borda descobertos.
10. Encerrar limpo.
