# Project skills

Skills in this folder are **project-local** procedures for CondoPartners agents. They follow the Agent Skills format (`SKILL.md` with YAML frontmatter) so Paperclip and compatible tools can scan them.

Company-wide skills (superpowers, graphify, ui-ux-pro-max, ponytail, caveman, taste-skill) live in the Paperclip company library — reference them from these skills; do not vendor their full text here.

## Available skills

| Skill | Purpose |
|-------|---------|
| [`working-on-a-task`](working-on-a-task/SKILL.md) | End-to-end loop from issue to PR |
| [`adding-an-api-module`](adding-an-api-module/SKILL.md) | Create a new Elysia module like `health` |
| [`adding-a-web-feature`](adding-a-web-feature/SKILL.md) | Add UI wired through Eden Treaty |

## Format

```md
---
name: skill-name
description: One-line routing description for agents.
---

...
```
